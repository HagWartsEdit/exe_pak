EXE PAK V11.3 — NEON OVERDRIVE

این آپدیت ظاهر فعلی EXE PAK را حفظ می‌کند و لایه انیمیشن سبک به آن اضافه می‌کند:
- نور متحرک در هدر و لوگو
- درخشش آرام و حرکت سینمایی در بخش Hero
- ذرات نئونی شناور در تصویر اصلی
- برق عبوری روی دکمه‌های اصلی
- ورود نرم کارت‌ها و پنل‌ها هنگام اسکرول
- نوار پیشرفت اسکرول بالای صفحه
- افکت Hover پیشرفته برای کارت‌ها و منوها
- رعایت تنظیم Reduce Motion برای کاربرانی که انیمیشن کمتر می‌خواهند

نصب:
1) ZIP را استخراج کن.
2) محتویات پروژه را در مخزن GitHub قبلی جایگزین کن و commit/push بزن.
3) در Cloudflare Worker با نام exe-pak، نسخه جدید را Deploy کن.
4) بعد از Deploy موفق، سایت را با Ctrl+F5 یا پنجره ناشناس تست کن.

توجه: این فایل آماده Deploy است، اما از اینجا به حساب Cloudflare تو دسترسی ندارم و Deploy زنده انجام نشده.
