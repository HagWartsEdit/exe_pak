EXE PAK V11.4 — NEON COMMAND CENTER

محتویات این آپدیت (بر پایه V11.3):
- مرکز فرمان (Command Palette) با Ctrl+K / ⌘+K و جستجوی دستورها
- میانبرهای سریع برای مودها، بازی‌ها، کانتر، آپلود، رتبه‌بندی و مود تصادفی
- حالت سینمایی با ذخیره انتخاب روی همان مرورگر
- پنل ماموریت روزانه با پیشرفت محلی و نوار XP نمایشی
- دکمه رفتن به بالای صفحه و میانبر / برای باز کردن مرکز فرمان
- رابط واکنش‌گرا و رعایت prefers-reduced-motion

مهم: XP ماموریت روزانه فقط محلی و نمایشی است و امتیاز سرور/حساب کاربر را تغییر نمی‌دهد.

نصب:
1) ZIP را استخراج کن.
2) محتویات را در مخزن GitHub پروژه جایگزین کن و commit/push بزن.
3) در Cloudflare Worker با نام exe-pak نسخه جدید را Deploy کن.
4) بعد از Deploy موفق، آدرس workers.dev را با Ctrl+F5 یا پنجره ناشناس آزمایش کن.

تست‌های محلی: سینتکس JS صفحه اصلی و Worker، بررسی تنظیمات wrangler.toml و سلامت ZIP.
این بسته از اینجا روی حساب Cloudflare منتشر نشده و آزمون زنده چندکاربره انجام نشده است.
