EXE PAK V11.4 — NEXUS DISCOVERY UPDATE

Added to the V11.3 project:
- Nexus discovery section on the homepage with links to mods, browser games, community chat, and random discovery.
- Quick command palette (Ctrl+K / Cmd+K) with keyboard navigation, filtering, Enter to open, and Escape to close.
- Floating back-to-top control.
- Neon glass panel sweep animation with prefers-reduced-motion support.
- Responsive layout for the new section.

The command palette uses existing pages and the discovery panel does not fabricate online data or rewards. This update has not been deployed to the live Cloudflare Worker. Run syntax and ZIP checks before deployment; then deploy the same project to the existing exe-pak Worker.
