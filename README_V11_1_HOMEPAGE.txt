EXE PAK V11.1 — HOME DASHBOARD UPDATE

این آپدیت صفحه اصلی را با الهام از طرح مرجع EXE PAK بازطراحی می‌کند:
- چیدمان داشبورد سه‌ستونه در نمایشگرهای بزرگ: منوی سریع سمت چپ، محتوای اصلی وسط و پنل اطلاعات سمت راست.
- هدر قوی‌تر، رنگ‌های نئونی بنفش/آبی، کارت‌های شیشه‌ای و قاب‌های نورانی.
- تصویر سرباز سایبرپانکی به‌عنوان بک‌گراند بخش Hero (فقط تصویر پس‌زمینه، نه اسکرین‌شات کامل سایت).
- پنل سمت راست برای پروفایل، آمار واقعی API، مودهای پرطرفدار و لینک‌های سریع کانتر/بازی‌ها/آپلود/چت.
- در موبایل، ستون‌های کناری پنهان می‌شوند تا محتوای اصلی خوانا بماند.
- اتصال‌ها و بخش‌های قبلی صفحه اصلی حفظ شده‌اند؛ پنل مودهای پرطرفدار از داده‌های واقعی پست‌ها ساخته می‌شود.

تست‌های انجام‌شده:
- بررسی ساختار HTML و وجود یک main/footer و ستون‌های کناری.
- بررسی نبود شناسه‌های تکراری در HTML.
- بررسی نحوی JavaScript با node --check.
- تست سلامت ZIP بعد از بسته‌بندی.

نکته: این بسته آماده بارگذاری/دیپلوی است؛ هنوز روی حساب زنده Cloudflare منتشر نشده.
